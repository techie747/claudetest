Suno API Setup
Four steps to connect your Suno account and start generating music.
01

Get Suno API Access

Sign up for Suno's API program at suno.com. Apply for API access under your account developer settings. Enterprise and creator tiers available.

02

Copy Your API Key

Once approved, copy your API key from the Suno developer dashboard. Keep it secret — never expose it client-side.

03

Configure the Engine

Create a .env file in this project with your key. The backend proxies all Suno calls server-side so your key stays secure.

04

Deploy & Embed

Deploy to any Node.js host (Railway, Render, Heroku, VPS). Grab the embed code above and paste it into any website.

.env Configuration
# Required — your Suno API key
SUNO_API_KEY=suno-your-key-here

# Optional — Suno API base URL (default: https://api.suno.ai)
SUNO_API_BASE=https://api.suno.ai

# Optional — comma-separated allowed embed origins (* = all)
ALLOWED_ORIGINS=https://yoursite.com,https://app.yoursite.com

# Optional — server port (default: 3000)
PORT=3000
